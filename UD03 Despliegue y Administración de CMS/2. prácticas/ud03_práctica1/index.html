    3.1: Introducción a los CMS y Despliegue Asistido de WordPress (Práctica)

    Parte 1: Ejemplo Práctico Guiado (Descarga, Configuración e Instalación)

    Sigue estos pasos en tu terminal para descargar el código fuente oficial de WordPress, preparar los permisos en Linux y ejecutar la famosa instalación de 5 minutos.

    Referentes de Evaluación y Concreción Curricular

    • Módulo Profesional: Aplicaciones Web (Código 0228) — 2º SMR (IES Joan Fuster)
    • Curso Académico: 2026-2027
    • Resultado de Aprendizaje (RA) trabajado:
      • RA3: Instala gestores de contenidos, identificando sus aplicaciones y configurando sus parámetros.
    • Criterios de Evaluación (CE) vinculados:
      • CE 3.a: Se ha valorado el uso y la utilidad de los gestores de contenidos.
      • CE 3.b: Se han instalado gestores de contenidos.
      • CE 3.c: Se han gestionado usuarios y grupos de usuarios.
      • CE 3.d: Se han personalizado las interfaces de los gestores de contenidos.
      • CE 3.f: Se han configurado los parámetros de los gestores de contenidos.

    Paso 1: Creación de la Base de Datos y Usuario en MariaDB

    Prepara el entorno de datos antes de tocar los archivos web.

    1. Abre tu terminal y accede a MariaDB: 
      sudo mariadb -u root
    2. Crea una base de datos y un usuario exclusivo ejecutando: 
      CREATE DATABASE db_wp_guiado CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'usr_wp_guiado'@'localhost' IDENTIFIED BY 'Wp2026!Pass';
GRANT ALL PRIVILEGES ON db_wp_guiado.* TO 'usr_wp_guiado'@'localhost';
FLUSH PRIVILEGES;
EXIT;

    Paso 2: Descarga y Extracción de WordPress

    Descarga la última versión de WordPress en español directamente desde los servidores oficiales mediante consola.

    1. Navega al directorio temporal del sistema: 
      cd /tmp
    2. Descarga el paquete comprimido: 
      wget https://es.wordpress.org/latest-es_ES.tar.gz
    3. Descomprime el archivo descargado: 
      tar -xvzf latest-es_ES.tar.gz
    4. Mueve la carpeta resultante al DocumentRoot de Apache renombrándola como wp_guiado: 
      sudo mv wordpress /var/www/html/wp_guiado

    Paso 3: Asignación de Permisos POSIX

    Asigna la propiedad al servidor web y aplica los permisos estrictos de seguridad.

    1. Transfiere la propiedad recursiva al usuario www-data: 
      sudo chown -R www-data:www-data /var/www/html/wp_guiado
    2. Aplica permisos 755 para las carpetas y 644 para los ficheros: 
      sudo find /var/www/html/wp_guiado/ -type d -exec chmod 755 {} \;
sudo find /var/www/html/wp_guiado/ -type f -exec chmod 644 {} \;

    Paso 4: Ejecución del Asistente Web

    1. Abre tu navegador y accede a: 
      http://localhost/wp_guiado/
    2. Haz clic en el botón ¡Vamos a ello!.
    3. Rellena el formulario de conexión con los datos del Paso 1:
    4. Nombre de la base de datos: db_wp_guiado
    5. Nombre de usuario: usr_wp_guiado
    6. Contraseña: Wp2026!Pass
    7. Servidor de la base de datos: localhost
    8. Prefijo de tabla: wp_test_
    9. Pulsa Enviar y Ejecutar la instalación.
    10. En la pantalla final, asigna un título a tu web y crea tu usuario de acceso al panel de administración. Nunca utilices la palabra admin como nombre de usuario. Utiliza tu propio nombre, por ejemplo juan_admin.

    Parte 2: Práctica Autónoma Evaluativa

    Realiza el despliegue de un segundo portal de forma individual, aplicando buenas prácticas de seguridad. Documenta tu trabajo para la evaluación.

    Escenario de Trabajo

    El departamento técnico del IES Joan Fuster te solicita desplegar un blog corporativo para el equipo de profesores de informática. Debe ser una instalación totalmente aislada de la anterior, con su propia base de datos, credenciales independientes y medidas de seguridad preventivas contra inyecciones SQL.

    Tareas a Realizar

    1. Creación del entorno de datos:
    2. Crea una base de datos denominada bd_blogtic.
    3. Crea un usuario denominado usr_blogtic con contraseña TicBlog2026!.
    4. Otorga privilegios a este usuario únicamente sobre la base de datos bd_blogtic.
    5. Descarga y preparación del sistema de archivos:
    6. Descarga WordPress en /tmp y muévelo a la ruta /var/www/html/blog_tic.
    7. Asigna los permisos correctos al usuario www-data.
    8. Instalación desde el navegador:
    9. Accede a http://localhost/blog_tic/.
    10. Completa la configuración de base de datos introduciendo un prefijo de tabla seguro y personalizado (por ejemplo jf_tic_).
    11. Configura el Título del sitio como: Blog Técnico SMX - IES Joan Fuster.
    12. Crea un usuario administrador con tu propio nombre (prohibido usar admin, administrador o root).
    13. Verificación de la base de datos:
    14. Accede a http://localhost/phpmyadmin.
    15. Entra en la base de datos bd_blogtic y verifica que todas las tablas creadas por el instalador (users, posts, options) comienzan por el prefijo que elegiste en el asistente web.

    Resolución de errores de escritura

    Si al rellenar los datos de conexión en el asistente web, WordPress te muestra un bloque de código y te pide crear manualmente el archivo wp-config.php, significa que te has saltado el paso de asignar la propiedad de la carpeta al usuario www-data. Revisa los comandos chown antes de continuar.
