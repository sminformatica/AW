    Unidad Didáctica 1: Aplicaciones y servidores web

    Introducción

    Las aplicaciones y los servidores web constituyen la base de la mayoría de los servicios disponibles en Internet y en las redes corporativas. En esta unidad didáctica se abordan los conceptos, tecnologías y herramientas fundamentales para comprender su funcionamiento, utilizando Apache como servidor web de referencia y PHP para introducir el procesamiento dinámico.

    A lo largo de la unidad, el alumnado estudiará la arquitectura cliente-servidor, los protocolos y puertos de red, la organización de los contenidos mediante el DocumentRoot y la gestión de servicios web. También aprenderá a configurar el servidor, administrar directorios, archivos y permisos, e integrar módulos de procesamiento dinámico. Finalmente, se realizarán pruebas desde el cliente para diferenciar la respuesta de contenidos estáticos y dinámicos y verificar el correcto funcionamiento de una aplicación web.

    Objetivos

    • Identificar los componentes, tecnologías y arquitecturas de las aplicaciones y los servidores web.
    • Comprender el modelo cliente-servidor, los protocolos web y la función de los servicios y puertos de red.
    • Instalar, configurar y comprobar el funcionamiento del servidor Apache.
    • Organizar los contenidos web mediante el DocumentRoot y la estructura de directorios del servidor.
    • Gestionar archivos, directorios y permisos aplicando buenas prácticas de administración.
    • Integrar módulos de procesamiento dinámico, como PHP, en Apache.
    • Verificar desde el cliente la respuesta de contenidos estáticos y dinámicos.

    Contenidos

    1. Aplicaciones web y arquitectura cliente-servidor
      • Componentes, tecnologías y arquitecturas de las aplicaciones web.
      • Protocolos HTTP/HTTPS y flujo de las peticiones y respuestas.
    2. Servidores web, servicios y puertos de red
      • Función de un servidor web y puertos habituales.
      • Instalación, gestión y comprobación de servicios web.
    3. Servidor Apache y organización de contenidos
      • Configuración básica de Apache.
      • DocumentRoot, directorios, archivos y permisos.
    4. Procesamiento estático y dinámico
      • Diferencias entre contenidos estáticos y dinámicos.
      • Integración de PHP y módulos de Apache.
    5. Pruebas y verificación de aplicaciones web
      • Acceso desde el cliente y comprobación de respuestas.
      • Diagnóstico básico de errores de configuración y permisos.
