    Práctica 1.4 Arquitectura de Bases de Datos en Entornos Web y Gestor MariaDB

    Ficha de la Sesión

    • Módulo: Aplicaciones Web (2º SMX)
    • Unidad de Trabajo: UD 2 — Bases de Datos para la Web
    • Sesión: Sesión 4 (1 hora - Introducción y Despliegue de MariaDB)
    • Entorno de trabajo: LliureX 21 / Ubuntu Desktop 24.04 LTS
    • Resultados de Aprendizaje: RA2 (Criterios a, b)

    Parte 1: Ejemplo Práctico Guiado (Instalación y Bastionado de MariaDB)

    Sigue atentamente estos pasos en tu terminal para instalar el motor de bases de datos MariaDB, comprobar su servicio y aplicar la configuración básica de seguridad.

    Paso 1: Instalación de paquetes de MariaDB

    1. Abre tu terminal (Ctrl + Alt + T).
    2. Instala el servidor y cliente de MariaDB: 
      sudo apt update
sudo apt install -y mariadb-server mariadb-client

    Paso 2: Verificación del estado del servicio

    1. Comprueba que el servicio mariadb está activo y configurado para arrancar con el sistema: 
      sudo systemctl status mariadb
    2. Verifica que el proceso está escuchando localmente en el puerto estándar 3306: 
      sudo ss -tulpn | grep :3306

    Paso 3: Ejecución del script de bastionado inicial

    Ejecuta el asistente de seguridad interactivo en la terminal:

    sudo mariadb-secure-installation

    Responde a las preguntas del asistente según estas indicaciones:

    1. Enter current password for root (enter for none): Pulsa Enter (no hay contraseña asignada inicialmente).
    2. Switch to unix_socket authentication? Escribe n y pulsa Enter.
    3. Change the root password? Escribe Y, pulsa Enter e introduce una contraseña para prácticas (por ejemplo: Smx2026!Pass).
    4. Remove anonymous users? Escribe Y y pulsa Enter.
    5. Disallow root login remotely? Escribe Y y pulsa Enter.
    6. Remove test database and access to it? Escribe Y y pulsa Enter.
    7. Reload privilege tables now? Escribe Y y pulsa Enter.

    Paso 4: Acceso a la consola interactiva de MariaDB

    Accede a la consola de administración ejecutando:

    sudo mariadb -u root -p

    Introduce la contraseña configurada en el paso anterior. Observa el prompt de bienvenida MariaDB [(none)]>.

    Para salir de la consola, escribe: 

    EXIT;

    Parte 2: Práctica Autónoma

    Realiza las siguientes tareas de forma individual en tu equipo para afianzar el control del motor de bases de datos mediante comandos básicos.

    Contexto de la Tarea

    El departamento técnico del IES Joan Fuster te solicita comprobar el estado del servicio de base de datos y listar la configuración inicial del motor para verificar que el bastionado se ha completado con éxito.

    Tareas a Realizar

    1. Inspección de Procesos y Puertos:

      • Utiliza el comando systemctl para verificar que el servicio mariadb.service está activo.
      • Utiliza el comando ss para identificar la dirección IP de enlace y el puerto donde escucha MariaDB.

    2. Consulta de Bases de Datos del Sistema:

      • Accede a la consola interactiva de MariaDB como usuario administrador (root).
      • Ejecuta la siguiente sentencia SQL para listar las bases de datos presentes en el motor: 
        SHOW DATABASES;
      • Comprueba que la base de datos test ya no aparece en el listado tras haber aplicado el bastionado de seguridad.

    3. Consulta de Cuentas de Usuario del Motor:

      • Dentro de la consola de MariaDB, ejecuta la consulta para listar los usuarios registrados y su host de conexión: 
        SELECT User, Host FROM mysql.user;
      • Anota qué usuarios aparecen y verifica que no existe ningún usuario anónimo (con el campo User en blanco).

    4. Comprobación de la Extensión PHP para MySQL:

      • Para que PHP pueda comunicarse con MariaDB en las próximas sesiones, instala la extensión correspondiente desde la terminal de Linux: 
        sudo apt install -y php-mysql
sudo systemctl restart apache2
      • Accede a http://localhost/info.php en tu navegador y busca el bloque mysqli o pdo_mysql para comprobar que el módulo aparece como enabled.

    Recordatorio de Sintaxis SQL

    Todas las sentencias dentro de la consola de MariaDB deben finalizar obligatoriamente con un punto y coma (;). Si pulsas Enter sin el punto y coma, el intérprete se quedará esperando en la línea siguiente mostrando una flecha ->.

    Entregables

    Genera un informe en formato PDF denominado UD02_S4_Apellido_Nombre.pdf que contenga:

    1. Captura 1: Salida del comando sudo ss -tulpn | grep :3306 en el terminal de Linux.
    2. Captura 2: Salida de la sentencia SHOW DATABASES; dentro de la consola interactiva de MariaDB.
    3. Captura 3: Salida de la consulta SELECT User, Host FROM mysql.user; mostrando los usuarios del motor.
    4. Captura 4: Navegador web mostrando el bloque mysqli activo en http://localhost/info.php.
