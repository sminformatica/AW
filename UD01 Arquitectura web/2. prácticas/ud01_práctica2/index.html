    Práctica 1.2: Ejemplo Práctico Guiado (Servicios, Puertos y DocumentRoot)

    Referentes de Evaluación y Concreción Curricular

    • Módulo Profesional: Aplicaciones Web — 2º SMX (IES Joan Fuster)
    • Resultados de Aprendizaje (RA) Referentes:
      • RA1: Instala servidores de aplicaciones web, evaluando sus características y entornos de aplicación.
    • Criterios de Evaluación (CE) Vinculados:
      • CE 1.a: Se han identificado los componentes de la arquitectura de un servidor web.
      • CE 1.b: Se ha comprobado el estado del servicio y la escucha en el puerto de red correspondiente.
      • CE 1.c: Se ha gestionado la estructura de directorios en el DocumentRoot y la asignación de permisos del sistema de archivos.

    Sigue atentamente los siguientes pasos en tu terminal para aprender a controlar el servicio web, verificar los puertos abiertos en tu sistema y estructurar directorios web.

    Paso 1: Comprobar el estado del servicio web

    1. Abre un terminal en tu equipo Linux (Ctrl + Alt + T).
    2. Comprueba el estado del servicio web Apache mediante el gestor del sistema: 
      sudo systemctl status apache2
    3. Observa la salida: si indica Active: active (running) en color verde, el servicio está en funcionamiento.
    4. Si estuviera detenido (inactive (dead)), arráncalo con: 
      sudo systemctl start apache2

    Paso 2: Verificar los puertos abiertos con ss

    Comprueba qué programas están escuchando conexiones de red en tu equipo.

    1. Ejecuta en el terminal: 
      sudo ss -tulpn | grep :80
    2. Analiza el resultado:
      • tcp: Protocolo de transporte.
      • LISTEN: El servicio está activo esperando clientes.
      • 0.0.0.0:80 o *:80: Está escuchando en el puerto 80 en todas las interfaces de red.
      • users:(("apache2",...)): Confirma que el proceso que ocupa el puerto es el servidor Apache.
      • apache2: El nombre del proceso que está escuchando en el puerto 80.

    Paso 3: Explorar el DocumentRoot predeterminado

    1. Navega hasta el directorio raíz de documentos web: 
      cd /var/www/html
ls -la
    2. Observa la presencia del archivo index.html inicial instalado por el sistema.

    Paso 4: Crear una sección web propia y ajustar permisos

    1. Crea una carpeta llamada taller1 dentro de la raíz web: 
      sudo mkdir /var/www/html/taller1
    2. Crea una página de bienvenida dentro de esa carpeta utilizando el editor de texto de consola nano: 
      sudo nano /var/www/html/taller1/index.html
    3. Introduce el siguiente código HTML básico: 
      <!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Taller Guiado - 2º SMX</title>
</head>
<body>
    <h1>Servicio Web Apache Operativo</h1>
    <p>Primer despliegue estático en el DocumentRoot de Linux.</p>
</body>
</html>
    4. Guarda el archivo pulsando Ctrl + O, Enter y sal con Ctrl + X.
    5. Ajusta los permisos para asegurar que el servidor pueda leer el archivo sin problemas: 
      sudo chown -R www-data:www-data /var/www/html/taller1
sudo chmod 755 /var/www/html/taller1
sudo chmod 644 /var/www/html/taller1/index.html
    6. Abre el navegador web y accede a: 
      http://localhost/taller1/
      Comprueba que visualizas el texto maquetado.

    Parte 2: Práctica Autónoma

    Realiza las siguientes tareas de forma individual y sin asistencia para demostrar que comprendes el flujo de servicios y la gestión de permisos en Linux.

    Escenario Profesional

    La dirección del IES Joan Fuster te ha encargado organizar la estructura de carpetas del servidor web para hospedar dos secciones independientes: 1. Una sección pública informativa sobre el ciclo formativo de SMX. 2. Un área técnica interna para almacenar documentación de red.

    Requisitos de la Tarea

    1. Estructura de Directorios:

      • Dentro de /var/www/html/, crea dos carpetas independientes:
        • /var/www/html/ciclo_smx/
        • /var/www/html/area_tecnica/

    2. Creación de Páginas HTML:

      • En /var/www/html/ciclo_smx/index.html, diseña una página HTML5 válida que contenga:
        • Un encabezado principal (<h1>) con el texto: Ciclo Formativo SMX - IES Joan Fuster.
        • Un párrafo que indique tu nombre completo y curso (2º SMX).
        • Una tabla (<table>) con dos columnas: Módulo Profesional y Profesor/a, incluyendo las tres asignaturas que cursas conjuntamente (Aplicaciones Web, Seguridad Informática y Servicios en Red).
      • En /var/www/html/area_tecnica/index.html, crea un documento sencillo con un encabezado <h1> que indique: Documentación Interna de Red.

    3. Gestión Estricta de Permisos:

      • Aplica la propiedad de usuario y grupo www-data:www-data a ambas carpetas y a sus archivos contenidos.
      • Configura los permisos exactos: directorios con 755 y archivos HTML con 644.

    4. Simulación y Diagnóstico de Error 403 Forbidden:

      • Retira deliberadamente los permisos de lectura a la página de la zona técnica ejecutando: 
        sudo chmod 000 /var/www/html/area_tecnica/index.html
      • Accede desde el navegador a http://localhost/area_tecnica/index.html y comprueba el error que muestra el servidor web.
      • Restaura los permisos correctos (644) y verifica que vuelve a cargar correctamente.

    5. Comprobación de Acceso por Red Local:

      • Averigua la dirección IP de tu tarjeta de red mediante el comando: 
        ip a
      • Accede desde el navegador web sustituyendo localhost por tu dirección IP real (por ejemplo http://192.168.X.X/ciclo_smx/).

    Verificación de Sintaxis HTML

    Asegúrate de cerrar todas las etiquetas HTML (</h1>, </p>, </table>, </body>, </html>) para que la página sea válida y se renderice de forma limpia en el navegador.

    Entregables

    Genera un informe técnico en formato PDF con el nombre UD01_S2_Apellido_Nombre.pdf que contenga:

    1. Captura 1: Salida del comando sudo ss -tulpn | grep :80 en la terminal mostrando el puerto 80 en escucha.
    2. Captura 2: Salida del comando ls -la /var/www/html/ciclo_smx/ donde se aprecien los permisos rw-r--r-- (644) y el propietario www-data.
    3. Captura 3: Navegador web mostrando la página http://localhost/ciclo_smx/ con la tabla de asignaturas y tu nombre visible.
    4. Captura 4: Navegador web mostrando el error 403 Forbidden obtenido durante la simulación del paso 4.
    5. Captura 5: Navegador web mostrando el acceso a la web utilizando la dirección IP privada de tu equipo en lugar de localhost.
