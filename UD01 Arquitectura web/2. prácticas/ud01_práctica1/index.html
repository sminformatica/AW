    Parte 1: Ejemplo Práctico Guiado (Inspección del Flujo Cliente-Servidor)

    Sigue estos pasos guiados en tu ordenador para aprender a inspeccionar la comunicación real entre tu cliente (el navegador) y un servidor web en producción.

    Paso 1: Abrir las Herramientas de Desarrollador

    1. Abre tu navegador web (Mozilla Firefox o Google Chrome/Chromium) en LliureX/Ubuntu.
    2. Presiona la tecla F12 en tu teclado (o haz clic derecho y selecciona Inspeccionar).
    3. Observa que en la parte inferior o lateral de la pantalla se abre un panel técnico con múltiples pestañas.
    4. Haz clic en la pestaña llamada Red (o Network en inglés).

    Consejo Pro

    Mantén la pestaña Red abierta antes de recargar o escribir una URL para asegurarte de capturar todas las peticiones iniciales (como recursos estáticos, imágenes, hojas de estilo o scripts).

    Paso 2: Realizar una Petición Web

    1. Con la pestaña Red abierta, escribe en la barra de direcciones del navegador: 
      http://info.cern.ch
      (Este es el primer sitio web de la historia, una página puramente estática en HTML que no utiliza cifrado HTTPS).
    2. Pulsa Enter.

    Paso 3: Analizar la Petición y Respuesta HTTP

    1. Verás que en la tabla de la pestaña Red aparece una fila correspondiente a la petición realizada.
    2. Haz clic sobre esa primera fila para desplegar el panel de detalles:
      • Método de la petición: GET (indica que el cliente solicita un recurso al servidor).
      • Código de estado: 200 OK (indica que el servidor procesó la petición con éxito).
      • Dirección remota / IP: La dirección IP del servidor del CERN que te ha atendido.
    3. Haz clic en la subpestaña Encabezados (o Headers) para examinar metadatos críticos:
      • Cabeceras de respuesta: Software del servidor web (Server), fecha y hora (Date), y tipo de contenido (Content-Type).
      • Cabeceras de petición: Información enviada por el navegador (como el agente de usuario User-Agent o los formatos aceptados Accept).

    Paso 4: Inspección de Petición por Consola con cURL

    En entornos de servidores Linux o sistemas headless, no siempre dispones de interfaz gráfica. Puedes realizar la misma petición HTTP directamente desde la terminal del sistema mediante utilidades de línea de comandos.

    1. Abre tu terminal en LliureX/Ubuntu (Ctrl + Alt + T).
    2. Ejecuta el comando curl con el parámetro -I para solicitar exclusivamente las cabeceras HTTP: 
      curl -I http://info.cern.ch
    3. Comprueba que el terminal te devuelve la respuesta directa enviada por el servidor: 
      HTTP/1.1 200 OK
Date: Fri, 28 Aug 2026 10:00:00 GMT
Server: Apache
Content-Type: text/html

    Funcionamiento de cURL

    El comando curl actúa como un cliente HTTP textual, permitiendo depurar protocolos web sin necesidad de renderizar el contenido HTML en un navegador.

    Parte 2: Práctica Autónoma

    Realiza las siguientes actividades de forma individual en tu puesto de trabajo. Anota y captura todas las evidencias requeridas para completar la entrega técnica.

    Actividad 1: Análisis de Códigos de Estado y Redirecciones

    1. Abre la herramienta de inspección (F12) en tu navegador web y sitúate en la pestaña Red.
    2. Escribe en la barra de direcciones: http://iesjoanfuster.edu.gva.es (Fíjate que estás escribiendo explícitamente http:// en lugar de https://).
    3. Observa detalladamente qué ocurre en la pestaña de red:
      • Localiza la primera petición realizada. ¿Qué código de estado numérico devuelve inicialmente el servidor (ej. 301, 302 o 307)?
      • ¿Hacia qué nueva URL con esquema seguro (https://) te redirige el servidor de forma automática para proteger la conexión?
    4. Escribe ahora una dirección deliberadamente errónea dentro de un dominio base válido, por ejemplo: https://www.gnu.org/pagina_inexistente_prueba_smx
      • Anota qué código de estado HTTP (4xx) devuelve el servidor web al no encontrar el recurso solicitado.

    Actividad 2: Consulta de Cabeceras desde la Terminal de Linux

    Abre la terminal de tu equipo y realiza las siguientes peticiones utilizando el comando curl -I:

    1. Realiza una petición HEAD/GET a la web del instituto: 
      curl -I https://iesjoanfuster.edu.gva.es
    2. Realiza una petición HEAD/GET a la web del proyecto Debian: 
      curl -I https://www.debian.org
    3. Para cada una de las dos consultas, identifica y documenta en tu informe:
      • El código de estado devuelto.
      • El software del servidor web que te atiende (analizando el campo Server: de la cabecera HTTP).
      • El tipo MIME devuelto (campo Content-Type:).

    Atención a la Sintaxis y Mayúsculas

    El parámetro -I en el comando curl debe ser una I mayúscula (--head). Si usas una i minúscula por error, el comando se comportará de forma diferente descargando e imprimiendo el código fuente completo de la página web en la terminal.
