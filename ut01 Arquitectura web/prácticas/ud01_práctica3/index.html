    Práctica1.3: Introducción al Procesamiento Dinámico con PHP y Módulos de Apache (Práctica)

    Ficha de la Sesión

    • Módulo: Aplicaciones Web (2º SMX)
    • Unidad de Trabajo: UD 1 — Arquitectura Web y Servidores HTTP
    • Sesión: Sesión 3 (1 hora - Consolidación y Verificación)
    • Entorno de trabajo: LliureX 21 / Ubuntu Desktop 24.04 LTS
    • Resultados de Aprendizaje: RA1 (Criterios a, b, c)

    Parte 1: Ejemplo Práctico Guiado (Instalación de PHP y Verificación de Módulos)

    Sigue los siguientes pasos en tu terminal de Linux para instalar el intérprete de PHP, enlazarlo con Apache y verificar su correcto funcionamiento dinámico.

    Paso 1: Instalación de PHP y el módulo de Apache

    1. Abre tu terminal (Ctrl + Alt + T).
    2. Instala el intérprete de PHP junto con el módulo de integración para el servidor web: 
      sudo apt update
sudo apt install -y php libapache2-mod-php

    Paso 2: Creación del archivo de comprobación

    1. Crea un archivo llamado info.php en la raíz de documentos: 
      sudo nano /var/www/html/info.php
    2. Añade el siguiente bloque de código PHP: 
      <?php
phpinfo();
?>
    3. Guarda el fichero con Ctrl + O, Enter y sal con Ctrl + X.

    Paso 3: Asignación de permisos y prueba en navegador

    1. Asigna los permisos correctos al archivo recién creado: 
      sudo chown www-data:www-data /var/www/html/info.php
sudo chmod 644 /var/www/html/info.php
    2. Abre el navegador web y accede a: 
      http://localhost/info.php
    3. Verifica que se visualiza una tabla de cabecera morada con los detalles del entorno PHP.

    Comprobación de Seguridad

    Haz clic derecho en la página cargada en el navegador y selecciona Ver código fuente de la página. Observa que no aparece la etiqueta <?php phpinfo(); ?>, sino miles de líneas de código HTML puro generado por el servidor.

    Parte 2: Práctica Autónoma

    Realiza las siguientes tareas de forma individual para validar tu capacidad de programar scripts básicos de diagnóstico y gestionar la configuración de PHP.

    Contexto de la Tarea

    El departamento técnico del IES Joan Fuster necesita verificar que el servidor local puede ejecutar código dinámico que procese variables del sistema antes de comenzar la instalación de gestores de bases de datos.

    Requisitos Técnicos

    1. Estructura de Directorio:

    2. Crea una carpeta llamada diagnostico_php dentro de /var/www/html/.

    3. Creación del Script Dinámico:

    4. Crea el archivo /var/www/html/diagnostico_php/prueba.php.

    5. El script debe generar una página HTML válida con:

      • Un encabezado <h1> con el texto: Diagnóstico del Servidor Web - IES Joan Fuster.
      • Un párrafo con la fecha y hora generada dinámicamente mediante la función date('d/m/Y - H:i:s').
      • Un párrafo que muestre la versión actual de PHP utilizando la constante predefinida PHP_VERSION.
      • Un párrafo que muestre el sistema operativo del servidor utilizando la constante PHP_OS.

    6. Permisos y Propiedad:

      • Aplica la propiedad www-data:www-data a la carpeta diagnostico_php/ y su contenido.
      • Asigna permisos 755 para la carpeta y 644 para el archivo prueba.php.

    7. Verificación de Respuesta:

      • Accede desde el navegador a http://localhost/diagnostico_php/prueba.php y recarga varias veces la página (F5) para verificar que los segundos de la hora se actualizan en cada petición.
      • Realiza una consulta desde la terminal con curl -I http://localhost/diagnostico_php/prueba.php y comprueba que la cabecera devuelta contiene la línea X-Powered-By: PHP/... o el código de respuesta 200 OK.

    Entregables

    Genera un documento PDF con el nombre UD01_S3_Apellido_Nombre.pdf que incluya:

    1. Captura 1: Salida del comando php -v en la terminal de Linux mostrando la versión del motor PHP instalada.
    2. Captura 2: Código fuente completo de tu archivo /var/www/html/diagnostico_php/prueba.php abierto en el editor de texto.
    3. Captura 3: Navegador web mostrando http://localhost/diagnostico_php/prueba.php con la fecha, versión de PHP y sistema operativo generados dinámicamente.
    4. Captura 4: Vista del "Código fuente de la página" en el navegador para demostrar que el cliente recibe solo HTML y no el código PHP original.
