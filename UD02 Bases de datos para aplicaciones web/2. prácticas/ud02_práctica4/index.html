    Parte 1: Ejemplo Práctico Guiado (Inspección de Charset y Cotejamientos en MariaDB)

    Sigue atentamente estos pasos para verificar las variables de codificación globales y comparar cómo afectan los cotejamientos a las consultas de texto.

    Paso 1: Comprobar las variables globales de codificación

    1. Abre tu terminal (Ctrl + Alt + T).
    2. Accede a la consola interactiva de MariaDB: 
      sudo mariadb -u root
    3. Ejecuta la siguiente consulta para examinar los juegos de caracteres activos en el servidor: 
      SHOW VARIABLES LIKE 'character_set_%';
    4. Observa que las variables principales (character_set_server, character_set_database, character_set_client) utilicen utf8mb4.

    Paso 2: Demostración de comparación insensible a mayúsculas y acentos (_ci)

    1. Selecciona la base de datos creada en la sesión anterior: 
      USE bd_taller_smx;
    2. Ejecuta una consulta buscando un término con diferencias de mayúsculas: 
      SELECT * FROM noticias WHERE titulo LIKE '%inicio%';
    3. Comprueba que el registro cuyo título contiene Inicio (con mayúscula inicial) es devuelto correctamente gracias al cotejamiento _ci (Case Insensitive).
    4. Sal de la consola: 
      EXIT;

    Parte 2: Práctica Autónoma

    Realiza las siguientes comprobaciones de forma individual utilizando phpMyAdmin para verificar el soporte completo de caracteres internacionales y emojis.

    Tareas a Realizar

    1. Verificación de la Base de Datos en phpMyAdmin:
    2. Accede a http://localhost/phpmyadmin con el usuario admin_smx.
    3. Selecciona la base de datos tienda_fuster.

    4. En la pestaña Operaciones, comprueba el bloque Cotejamiento. Si no estuviera en utf8mb4_unicode_ci, cámbialo en el desplegable y pulsa Continuar.

    5. Prueba de Inserción de Caracteres Especiales y Emojis:

    6. Abre la tabla productos de la base de datos tienda_fuster.
    7. Ve a la pestaña Insertar y añade un nuevo artículo con los siguientes datos:
      • referencia: SMX-EMOJI
      • nombre: Kit de Herramientas de Red 🛠️ (Edición Especial València / Castelló)
      • precio: 39.95
      • stock: 8
      • descripcion: Incluye crimpadora para conectores RJ-45, pelacables y comprobador tester. ¡Ideal para talleres de SMX! ⭐⭐⭐⭐⭐

    8. Haz clic en Continuar.

    9. Comprobación de Integridad:

      • Ve a la pestaña Examinar y localiza el registro insertado.
      • Verifica que tanto el emoji del maletín de herramientas (🛠️), las estrellas (⭐) como los caracteres especiales con acentos abiertos y diéresis (è, ó, ï) se leen y visualizan con total claridad sin mostrar símbolos rotos (? o ``).

    10. Consulta con Filtro Insensible a Acentos:

      • Haz clic en la pestaña superior Buscar dentro de la tabla productos.
      • En el campo nombre, busca el término valencia (escrito todo en minúsculas y sin acento).
      • Pulsa Continuar y comprueba que MariaDB localiza el artículo València gracias a las reglas del cotejamiento utf8mb4_unicode_ci.

    Verificación Rápida

    Si en alguna tabla observas que los emojis se reemplazan por signos de interrogación (???), significa que esa columna específica fue creada como utf8 o latin1 en lugar de utf8mb4. Puedes cambiar el cotejamiento de esa columna individual desde la pestaña Estructura > Cambiar.

    Entregables

    Genera un documento PDF con el nombre UD02_S2.4_Apellido_Nombre.pdf que contenga:

    1. Captura 1: Salida del comando SHOW VARIABLES LIKE 'character_set_%'; en la consola de MariaDB.
    2. Captura 2: Pestaña Examinar de phpMyAdmin mostrando el registro SMX-EMOJI con los emojis y tildes correctamente renderizados.
    3. Captura 3: Resultado de la búsqueda por la palabra valencia (sin acento) mostrando cómo el motor encuentra el registro que contiene València.
    4. Respuesta redactada: Breve justificación técnica de por qué es obligatorio usar utf8mb4 en lugar del antiguo utf8 en cualquier aplicación web actual.
