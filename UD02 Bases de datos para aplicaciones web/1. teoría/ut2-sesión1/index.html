    2.1: Despliegue del Motor MariaDB y phpMyAdmin en Linux

    En esta sesión de taller vas a aprender a instalar y poner en marcha la capa de datos de la pila LAMP sobre tu sistema GNU/Linux (LliureX / Ubuntu 24.04 LTS). Conectarás el motor de base de datos relacional MariaDB con el servidor Apache y desplegarás la herramienta gráfica de administración phpMyAdmin.

    2.1 ¿Qué es un SGBD y qué papel cumple en la Web?

    Un Sistema Gestor de Bases de Datos (SGBD) es el servicio encargado de almacenar, indexar, proteger y servir la información estructurada que maneja una aplicación web.

    En una web dinámica: * El servidor web (Apache) recibe la petición HTTP del usuario. * El intérprete PHP ejecuta el código y envía consultas al motor de base de datos. * El motor MariaDB busca la información en sus tablas y devuelve los registros a PHP. * PHP procesa los datos, genera el documento HTML y Apache lo entrega al navegador.

    2.2 MariaDB y el Proceso de Bastionado

    MariaDB es un gestor de bases de datos relacionales libre derivado de MySQL. Funciona como un servicio del sistema (mariadb.service) escuchando peticiones en el puerto 3306 TCP.

    Tras su instalación inicial, el motor incluye ajustes por defecto inseguros (usuarios anónimos, base de datos de pruebas accesible y autenticación permisiva). Por este motivo, siempre se debe ejecutar la herramienta de bastionado mariadb-secure-installation, la cual:

    1. Elimina las cuentas de usuarios anónimos.
    2. Deshabilita el acceso remoto directo a la cuenta de administración root.
    3. Elimina la base de datos test y sus permisos asociados.
    4. Recarga las tablas de privilegios en memoria.

    2.3 Administración Gráfica con phpMyAdmin

    phpMyAdmin es una aplicación web escrita en PHP diseñada para administrar servidores MariaDB/MySQL a través de un navegador web.

    En lugar de interactuar exclusivamente por línea de comandos mediante sentencias SQL, phpMyAdmin proporciona una interfaz gráfica para:

    • Visualizar bases de datos, tablas, campos y relaciones.
    • Crear y modificar registros con formularios interactivos.
    • Administrar cuentas de usuario y asignar privilegios.
    • Exportar e importar copias de seguridad en formato .sql.

    2.4 Requisitos de Extensión PHP para Bases de Datos

    Para que Apache y phpMyAdmin puedan dialogar con MariaDB, PHP necesita tener activos módulos específicos:

    • php-mysql / php-mysqli: Conector para ejecutar consultas y transacciones contra motores MySQL/MariaDB.
    • php-mbstring: Gestión de cadenas de texto y caracteres especiales multibyte (tildes, caracteres internacionales).
    • php-zip: Compresión y descompresión de archivos de volcado y temas.

    Si estos módulos no están instalados o habilitados en /etc/php/8.3/apache2/, phpMyAdmin no podrá arrancar y mostrará un error de dependencias.
