    Programación Didáctica y Contenidos del Módulo: Aplicaciones Web (2º SMX)

    Bienvenido al módulo profesional de Aplicaciones Web. En este espacio formativo vas a adquirir las competencias técnicas necesarias para desplegar, administrar, mantener y asegurar servicios y gestores de contenidos web en entornos Linux (LliureX / Ubuntu).

    El curso se divide en dos grandes etapas formativas: la Fase Pre-Empresa (Septiembre a Enero), centrada en capacitarte de forma intensiva en administración de bases de datos, despliegue profesional de WordPress, tiendas virtuales y migraciones antes de tu salida a la Formación en Centros de Trabajo (FCT / Dual); y la Fase de Retorno (Mayo a Junio), donde trabajarás con plataformas de teleformación y nubes privadas colaborativas.

    A continuación, dispones del desglose de las Unidades Didácticas (UD) que componen el módulo.

    Bloque 1.

    UD 1: Arquitectura Web y Fundamentos de Servidores

    En esta unidad inicial vas a asentar las bases del funcionamiento de las redes y servicios web antes de realizar instalaciones complejas:

    • El modelo Cliente-Servidor: Roles del navegador (User-Agent) y del servicio web (Daemon/Host).
    • Protocolos de comunicación: Funcionamiento detallado de HTTP y HTTPS (puertos 80 y 443 TCP).
    • Tipos de recursos web: Diferenciación técnica entre páginas estáticas (HTML/CSS/JS) y dinámicas (scripts interpretados en el servidor).
    • Códigos de estado HTTP: Diagnóstico de respuestas mediante códigos de éxito (2xx), redirecciones (3xx), errores de cliente (4xx) y errores de servidor (5xx).
    • Herramientas de inspección: Uso de las herramientas de desarrollador del navegador (F12) y peticiones HTTP desde terminal mediante curl.
    • Introducción a servidores locales: Arquitectura del servidor Apache2 en Linux y control básico del servicio.

    UD 2: Bases de Datos para Aplicaciones Web y phpMyAdmin

    Toda aplicación web dinámica requiere persistencia de datos. En esta unidad aprenderás a gestionar los almacenes de información de forma visual y estructurada:

    • El motor de base de datos relacional: Rol de MariaDB/MySQL en la arquitectura de un CMS.
    • Administración gráfica con phpMyAdmin: Acceso seguro, creación y parametrización de bases de datos.
    • Estructura y tipos de datos: Juegos de caracteres, codificación UTF-8 internacional (utf8mb4) y cotejamientos (collations).
    • Gestión de usuarios y seguridad: Creación de cuentas dedicadas, asignación de contraseñas robustas y aplicación estricta del principio de menor privilegio sobre bases de datos individuales.
    • Copias de seguridad y contingencia: Exportación de volcados de datos (dumps SQL con sentencias DDL y DML) e importación de copias de seguridad para restauraciones.

    UD 3: Despliegue y Administración de CMS (WordPress Esencial)

    Aprenderás a desplegar y gestionar el gestor de contenidos más utilizado del mundo:

    • Concepto y tipología de CMS: Plataformas de publicación web, blogs y portales corporativos.
    • Instalación asistida y requisitos previos: Preparación del directorio web, vinculación con bases de datos y configuración del archivo wp-config.php.
    • Arquitectura de contenidos: Diferencias entre entradas, páginas estáticas, categorías taxonómicas y etiquetas.
    • Gestión multimedia y menús: Organización de la biblioteca de medios y configuración de menús de navegación jerárquicos.
    • Administración de perfiles y usuarios: Roles del sistema (Administrador, Editor, Autor, Colaborador y Suscriptor) y asignación de permisos de publicación.
    • Ecosistema de temas y plugins: Instalación, activación y personalización de plantillas visuales y módulos de funcionalidad básica desde repositorios oficiales.

    UD 4: WordPress Profesional, Maquetación Visual y Comercio Electrónico

    En esta unidad profundizarás en las herramientas demandadas en entornos laborales reales:

    • Constructores visuales modernos: Maquetación con el editor de bloques nativo Gutenberg y constructores visuales (Elementor).
    • Diseño web adaptable (Responsive Design): Adaptación y maquetación de sitios para pantallas de escritorio, tabletas y dispositivos móviles.
    • Comercio Electrónico con WooCommerce: Instalación y parametrización de tiendas online completas.
    • Gestión de catálogo y ventas: Creación de productos simples y variables, gestión de inventario, atributos y configuración de métodos de envío.
    • Pasarelas de pago: Configuración de pasarelas de pago seguras en modo de prueba (Sandbox) y transferencias bancarias locales.
    • Optimización Web y SEO Básico: Uso de formatos de imagen ligeros (.webp), optimización de velocidad de carga (WPO) y estructura de enlaces permanentes amigables para motores de búsqueda.

    UD 5: Mantenimiento, Copias de Seguridad y Migración Web

    Aprenderás a mantener la integridad, trasladar proyectos y proteger aplicaciones en producción:

    • Estrategias de respaldo integrales: Copias de seguridad automáticas de ficheros y bases de datos hacia almacenamiento en la nube mediante UpdraftPlus.
    • Metodología de migración web: Empaquetado, traslado y clonación completa de sitios web sin pérdida de datos ni rotura de enlaces mediante Duplicator.
    • Bastionado básico de WordPress: Ocultación de banners informativos, cambio de la URL por defecto de acceso administrativo (wp-login.php), protección contra ataques de fuerza bruta y restricción de permisos en el sistema de ficheros.
    • Planes de contingencia y recuperación: Restauración ante caídas y desastres en entornos de producción.

    Bloque 2.

    UD 6: Entornos Virtuales de Aprendizaje (LMS - Moodle)

    En el periodo posterior a la estancia formativa en empresas, estudiarás las plataformas de teleformación:

    • Arquitectura de una plataforma de aprendizaje (LMS): Estructura del software Moodle y requisitos del servidor web.
    • Instalación y parametrización: Configuración de directorios de datos (moodledata), límites de subida de ficheros en PHP y ajustes del sitio.
    • Administración académica: Creación de categorías, diseño de cursos formativos, métodos de matriculación y asignación de roles (profesor, estudiante, creador de cursos).
    • Recursos y evaluación: Configuración de libros de calificaciones, módulos de tareas, foros y cuestionarios evaluativos.
    • Copias de seguridad en LMS: Respaldo individual de cursos, restauración y migración de contenidos formativos.

    UD 7: Nube Privada y Ofimática Colaborativa (Nextcloud)

    Concluirás el módulo desplegando soluciones de almacenamiento e infraestructura colaborativa corporativa:

    • Soluciones de almacenamiento cloud autoalojadas: Arquitectura de Nextcloud y alternativas a servicios propietarios.
    • Gestión de almacenamiento y usuarios: Creación de cuentas corporativas, asignación de cuotas de disco por departamento y grupos de trabajo.
    • Colaboración y sincronización: Carpetas compartidas con permisos granulares, control de versiones de ficheros y acceso mediante protocolo WebDAV.
    • Herramientas ofimáticas integradas: Configuración de calendarios compartidos, gestores de contactos y edición colaborativa de documentos.
    • Auditoría y cierre de proyectos: Revisión de registros de acceso, monitorización del estado del servidor y entrega de proyectos finales integrados.
